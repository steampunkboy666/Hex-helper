# Hex Helper · 海克斯大乱斗助手

选人阶段、对局内商店、海克斯三选一，三个环节自动给出推荐。数据来自 aramgg.com（国服海克斯大乱斗统计，每日更新），op.gg 作备用；英雄名/头像/装备价格来自腾讯官方数据。

## 使用
1. 双击 `HexHelper.exe`（会弹一次管理员确认；国服客户端/游戏通常以管理员运行，助手需同级权限才能读到客户端并显示在游戏上方）。
2. 程序常驻托盘，控制台窗口里能看到各部分状态。**先开助手，再开游戏/排队均可。**
3. **选人阶段**：进入大乱斗选人后自动弹出悬浮窗，**贴在客户端左侧（或上方/右侧）的空白处，不挡客户端**；空白够大时显示完整卡片，空白小时显示紧凑列表（梯队、胜率、排名、3 件装备、各稀有度最强强化）。列出当前英雄和板凳席英雄的强度梯队/排名、胜率、推荐出装、白银/黄金/棱彩强化推荐，排名最高者标 ★。可拖动，「关闭本局」本场不再显示。
4. **对局中打开商店**：画面一侧自动出现该英雄**除鞋子外胜率最高的 3 件装备**（单件胜率与场次来自 op.gg），下面是 3 套**不含鞋子**的核心三件套（op.gg 三件套统计；拿不到时用 aramgg 出装并去掉鞋子）。排序时场次少的胜率会向英雄平均胜率收缩，避免几十场的偶然高胜率排到前面，界面显示的仍是原始胜率；逐件标注已拥有 ✓ / 当前买得起 / 还差多少金币，关闭商店自动消失。
5. **出现海克斯三选一（3/7/11/15 级）**：按“综合分 = 单项胜率 + 组合加分 + 联动”排序。组合加分来自 aramgg 统计的该英雄高胜率三件强化组合：已选的强化越能和候选凑成这些组合，加分越多（最多 +6 分）；联动为关键词推断（最多 ±2.5 分）。自动识别三个选项（系统自带 OCR），给出各自对该英雄的胜率/梯队/排名、与已选强化及出装路线的适配度、后续可搭配的强化，并标出最推荐的一个。选择后用点击位置自动记录“已选强化”（`Ctrl+Alt+Z` 可撤销）。
6. 面板点击穿透、不抢焦点，不会影响操作；切到别的窗口时自动收起。

## 商店面板
按游戏里的商店键（默认 `P`，键位不同请改 `data/settings.json` 的 `shop_key`）打开商店时面板出现，再按一次或按 `Esc` 关闭时消失；聊天打字（回车后）里的 P 不算。
用鼠标点商店按钮开关商店时程序无法得知，请用 `Ctrl+Alt+S` 手动开关。（画面识别商店的方案在实机上不可靠：商店面板半透明，底色随地图变化，已停用。）

## 快捷键（全是组合键，不会和游戏按键冲突；可在 `data/settings.json` 修改）
`Ctrl+Alt+S` 手动开关商店面板 · `Ctrl+Alt+A` 强化速查（该英雄各稀有度最强强化）· `Ctrl+Alt+Z` 撤销上一个已选强化 · `Ctrl+Alt+H` 隐藏/显示全部面板

## 不同电脑的适配
- **分辨率/宽高比/显示缩放**：面板大小按游戏分辨率自动缩放（以 2560x1440 为基准）；画面识别区域按“画面高度”从中心计算，16:9、16:10、21:9 超宽屏、4:3 都能对上；Windows 显示缩放（125%/150%）已考虑；游戏在副屏上时面板也跟到副屏。
- **小地图、装备栏、技能栏**：位置和大小因人而异（小地图大小可调、可左右互换）。面板竖直方向固定在“比分栏下方到画面 58% 之间”，不往下压——小地图最大约占画面下方 42%，装备栏/技能栏/商店按钮都在下方，所以无论怎么设置都不会被盖住。想改范围：`data/settings.json` 里的 `panel_top`/`panel_bottom`（占画面高度的比例）。
- **商店面板位置**：商店可以被拖动、界面缩放也会改变它的大小。每次打开商店时程序会从画面里量出它的左右边缘（关闭后再对比一次，量准后记在设置里，下次同分辨率直接用），面板据此避让；商店被拖到偏好的那一侧时，自动换到另一侧。
- **三选一卡片位置**：识别到卡片后按实际间距算出卡片左右边缘，面板贴着卡片外侧摆放。
- **客户端的大小和位置**：选人窗口自动找客户端窗口（只认可见的主窗口、去掉 Win10 的隐形阴影边），贴在客户端左/上/右侧的空白处；客户端被移动或缩放后 1 秒内跟着重新摆放；客户端在哪块显示器上就用哪块。你手动拖过选人窗口后就保持你放的位置。
- **在游戏里手动调**：`Ctrl+Alt+]` 放大 / `Ctrl+Alt+[` 缩小 / `Ctrl+Alt+,` 放左边 / `Ctrl+Alt+.` 放右边（刻意没用方向键：部分 Intel 显卡驱动用 Ctrl+Alt+方向键旋转屏幕）。
- 每局开始时日志和诊断文件会记下这台机器的游戏分辨率、显示器、显示缩放、已记住的商店位置，以及游戏自己的界面设置（小地图大小等，读得到才记）；换机器后面板位置不对时把 `data` 文件夹发过来即可排查。

## 显卡开启动态刷新率（G-Sync / FreeSync）时闪屏
三选一界面停留太久闪屏、随后显卡驱动报错，是“动态刷新率 + 悬浮窗长时间压在游戏上 + 程序读屏”叠加触发的。默认开启**防闪烁模式**（`data/settings.json` 的 `overlay_safe`）：
- 面板改为不透明的普通窗口（不再用逐像素半透明），也不再使用“截屏排除”这种特殊显示属性（改为截图时把面板区域涂黑）；
- 三选一认全后不再每秒读屏：选择/刷新都要点击，点击后才复查一次，另外每 6 秒复查一次；
- 三选一推荐面板显示 25 秒后自动收起（`offer_panel_secs`，0 为一直显示），刷新出新选项会重新显示，`Ctrl+Alt+A` 可随时再调出来。
如果仍然闪屏，可以在显卡控制面板里只对“全屏模式”启用 G-Sync/FreeSync（游戏用的是无边框窗口，就不会再走动态刷新率），这是显卡设置，程序不会替你改。

## 性能说明
面板内容离屏排版后渲染成一张图，窗口只负责显示：位置/内容不变就不重绘，不再销毁重建控件，也不再反复置顶。
画面识别只在需要时做（商店：按键/点击后对比两张小图；海克斯：平时 4 秒一次、升级后和开局 1.2 秒一次，识别中间区域）；游戏不在前台时全部停止并收起面板；程序整体运行在“低于正常”优先级。
无边框全屏游戏上方只要有悬浮窗，Windows 就需要合成画面，**帧数会有一点点损失，这是 Windows 的机制，无法完全消除**；面板只在商店/三选一时出现，其余时间窗口是隐藏的，不产生开销。

## 数据来源与降级
- **主源 aramgg.com**：英雄梯队/胜率/选取率、每个英雄的海克斯强化胜率、核心出装。
- **备用 op.gg**：aramgg 不可用时自动切换，只有梯队/排名/综合分，**没有胜率**，界面会明确标注；出装沿用本地旧缓存。
- **最后兜底 douhunwiki.cn**：仅在前两者都失败、又没有任何缓存时使用（数据可能很旧），某些英雄样本不足没有出装时也用它补出装，界面会标“旧数据”。
- 榜单每 6 小时刷新一次，英雄详情只在选人/进游戏时按需获取并缓存 12 小时；同一站点请求间隔 ≥0.4 秒，开 gzip，请求量很小。aramgg 条款禁止“以滥用速率抓取”，请勿把请求频率改高。
- 两个站点都没有公开 API，本程序是解析它们的公开页面/数据文件：站点改版时解析可能失效（会自动降级到备用源，自检页会提示）。

## 换电脑 / 出问题时：环境自检
控制台里有“环境自检”区：逐项检查系统版本、管理员权限、PowerShell、中文 OCR、网络（数据站和图片站）、数据、数据目录、显示器、客户端/游戏窗口，红/黄/绿标注并给出修复办法。
启动时自动检查一次，有问题会自动弹出控制台；也可点“重新自检”。点“导出诊断文件”会生成 `data/diagnostic.txt`（不含客户端令牌），到 [Issues](https://github.com/steampunkboy666/Hex-helper/issues/new/choose) 选「问题反馈」并附上它即可定位。

## 携带
把 `HexHelper.exe` 单独拷走即可运行；运行后同目录会生成 `data/`（缓存、设置、日志）。需要联网下载数据（缓存 6 小时）。
启动时会到 GitHub 查一次有没有新版本，有的话控制台顶部出现下载链接（只提示，不会自动下载；不想检查可把 `data/settings.json` 的 `check_update` 改为 `false`）。
下载后可核对文件校验码（每个 Release 的说明里都有 SHA256）：PowerShell 里运行 `Get-FileHash HexHelper.exe`。
需要 Windows 10/11；海克斯识别用到系统自带中文 OCR（简体中文系统默认有，没有时：设置→时间和语言→语言→添加简体中文并勾选“文字识别”）。

## 说明与限制
- 只读取：本机客户端接口(LCU)、游戏自带的 Live Client Data API、屏幕像素和按键状态；不注入、不读写游戏内存、不模拟输入。
- 强化的胜率/梯队/排名、三件组合胜率、单件装备胜率都是数据源的真实统计；“联动/适配度”是对强化描述做关键词归类的推断，分值较小。aramgg 每个英雄只公开胜率最高的 5 个三件组合，不在其中的搭配只能靠关键词推断。
- 商店感知、海克斯三选一识别、点击记录已用模拟窗口验证，真实对局里的海克斯三选一识别还需要你再测一次；若不准，点控制台“导出诊断文件”，把 `data/diagnostic.txt`（含最近一次 OCR 识别到的文字）和 `data/ocr/cap0.png`、`cap1.png` 发给开发者。
- 杀毒软件可能对未签名的单文件 exe 报毒（PyInstaller 打包的通病），需要时添加信任。
- 数据日期显示在选人窗口标题栏和控制台，数据站点不更新时推荐会过时。

## 开发
```bash
py -3 -m pip install -r requirements.txt
py -3 main.py --demo        # 不开游戏，模拟一整局流程看效果
py -3 main.py               # 正常运行（需要以管理员身份，国服客户端/游戏通常是管理员权限）
build.bat                   # 打包成 dist\HexHelper.exe
```
测试：`tests/test_layout.py`（多显示器/商店与卡片位置计算）、`tests/test_real_offer.py`（用实机截图验证海克斯识别，含中文路径和连续识别压力测试）、`tests/test_vision.py`（模拟游戏窗口验证识别链路）、`tests/test_fallback.py`（数据源降级）。

代码结构：`app.py` 主控制器与各后台线程 · `ui.py` 所有窗口 · `vision.py` 截屏与系统 OCR · `layout.py` 布局计算（纯函数）· `advisor.py` 推荐算法 · `data_source.py`/`sources.py` 数据获取与降级 · `lcu.py`/`live.py` 客户端与对局接口 · `winfx.py` Win32 小工具。
